ลูกหนี้ OP เบิกได้ลูกหนี้ IPD เบิกได้ลูกหนี้ IPD UCลูกหนี้ OP UC ON TOPลูกหนี้ OP STPลูกหนี้ IP STPลูกหนี้ OP LGOลูกหนี้ IP LGO

ชนลูกหนี้รายตัวสิทธิ STP (บุคคลที่มีปัญหาสถานะและสิทธิ) กับ REP — ผู้ป่วยใน

จับคู่ด้วย AN · ถ้าไม่พบ AN ใช้ HN + วันจำหน่าย · ประมวลผลในเบราว์เซอร์ ไม่ส่งข้อมูลออกนอกเครื่อง

คู่มือดึงข้อมูลลูกหนี้ STP IPD จาก HOSxP XE (SQL)

ขั้นตอน

  1. กดปุ่ม คัดลอก SQL ด้านล่าง
  2. แก้ช่วงวันจำหน่ายในบรรทัด WHERE a.dchdate BETWEEN '2025-10-01' AND '2026-09-30' (รูปแบบ YYYY-MM-DD ปี ค.ศ.) ค่าตั้งต้นคือปีงบ 2569
  3. รันใน HOSxP XE (เมนู SQL Query) หรือโปรแกรมที่ต่อ PostgreSQL ของ HOSxP ได้ เช่น pgAdmin หรือ DBeaver
  4. Export ผลลัพธ์เป็น Excel (.xls/.xlsx) หรือ CSV อย่าเปลี่ยนชื่อคอลัมน์
  5. ลากไฟล์ที่ได้มาวางในกล่องด้านล่างพร้อมไฟล์ REP STP IPD (.xls หลายไฟล์ หรือ .zip)

หลักการของ SQL

  • ดึง admission ที่จำหน่ายแล้วจาก an_stat ในช่วงวันจำหน่ายที่กำหนด
  • เลือกเฉพาะสิทธิหลักของ admission ที่ pttype.nhso_code = 'ST' หรือ pttype.hipdata_code = 'STP'
  • เอาเฉพาะรายที่มียอดเรียกเก็บ (uc_money > 0)
ข้อควรรู้: SQL นี้ดูสิทธิจาก an_stat.pttype (สิทธิหลักตอนจำหน่าย) เท่านั้น ถ้า admission เปลี่ยนสิทธิกลางทางหรือมี STP เป็นสิทธิรอง จะไม่ถูกดึงมา และ REP ที่หน้าเว็บขึ้นว่า “ไม่มีในลูกหนี้” อาจเป็นรายเหล่านี้ ให้ตรวจสิทธิใน HOSxP ของ AN นั้นอีกครั้ง
SELECT
    a.dchdate AS dchdate,
    a.hn AS hn,
    a.an AS an,
    p.cid AS cid,
    COALESCE(p.pname,'') || p.fname AS fname,
    p.lname AS lname,
    COALESCE(a.uc_money,0) AS debt_amount
FROM an_stat a
JOIN patient p ON p.hn = a.hn
JOIN pttype pt ON pt.pttype = a.pttype
WHERE a.dchdate BETWEEN '2025-10-01' AND '2026-09-30'
  AND (pt.nhso_code = 'ST' OR pt.hipdata_code = 'STP')
  AND COALESCE(a.uc_money,0) > 0
ORDER BY a.dchdate, a.an;

รูปแบบไฟล์ที่รองรับ
  • ไฟล์ลูกหนี้ ต้องมีคอลัมน์ an, hn, dchdate, debt_amount (มี cid, fname, lname ด้วยยิ่งดี) ชื่อคอลัมน์ภาษาไทย เช่น “วันจำหน่าย”, “ยอดลูกหนี้” ก็อ่านได้
  • ไฟล์ REP คือ “รายละเอียดผลการตรวจสอบชดเชยค่าบริการทางการแพทย์บุคคลที่มีปัญหาสถานะและสิทธิ” (REPxx-yymmdd-IPD) ที่ดาวน์โหลดจาก e-Claim ใส่ได้ทั้งไฟล์เดี่ยวและ .zip
  • 1 AN ใน REP อาจมีหลายบรรทัด (IPNormal, IPRefer, S1801/S1802 ค่าพาหนะ, FP002 ฯลฯ) ระบบรวม “รวมจ่ายชดเชยทั้งสิ้น” ทุกบรรทัดของ AN เดียวกัน และตัดบรรทัดซ้ำเมื่ออัปโหลดไฟล์เดียวกันซ้ำ
  • AN ที่พบในหลายงวด REP จะติดป้าย “หลายงวด” ให้ตรวจว่าเป็นการจ่ายเพิ่มหรือข้อมูลซ้ำ
ใส่ไฟล์ลูกหนี้และไฟล์ REP แล้วระบบจะแสดงยอดที่ได้รับชดเชย ส่วนต่าง และรายที่ยังไม่พบใน REP
